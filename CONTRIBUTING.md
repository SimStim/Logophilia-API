# Contributing

This project is a small business API, developed and maintained for its intended use within the business. It is not a
community-driven development project, and external code contributions are neither expected nor solicited.

However, if you find a bug, an unexpected behavior, a security issue, or anything that doesn't seem right, please let us
know!

Bug reports, observations, and constructive feedback are always welcome. You don't need to provide a fix, write code, or
even understand why something went wrong. Just tell us what you encountered.

We'd much rather hear about a problem than have it go unnoticed.
